## 阅读边界

- 用户于 2026-11-13 明确：原型顶栏、左侧导航栏、页面编号切换和外围底栏用于说明 UI 结构，不属于正式软件界面。以标注红框内的主体区域作为页面实现依据。
- 正式应用由主体内容铺满窗口，通过“选择设备 → 进入工作台”、工作台内“返回设备列表”及设备页的连接指引入口完成操作流程；不保留演示用的全局页面切换导航。
- HTML 与截图说明页面结构及交互意图，不代表功能已实现。原型依赖外部 Tailwind、字体和图片，截图中存在字体回退、图片缺失及重复设备选择器等导出问题。
- P3 使用模拟命令输出、固定设备参数和随机 FPS；手机内容是 HTML 示意，不是真实视频。实现时必须接入真实数据。
- `cmd sensor mock-hinge`、`cmd sensor set-hinge-angle` 和固定设备状态编号是原型中的演示写法，不能据此承诺所有 Android 设备可用。
- P2 无线配对页混用了扫码说明和配对码表单；产品要求以 [PRD](../PRD.md) 的连接流程为准。
- DS 的通用工作站说明包含脚本、反编译、文件管理等扩展愿景。首版范围以 PRD 为准，不因设计规范提到某功能就自动扩展开发范围。

## 视觉落地规则

- 保留深色分层背景、绿色主操作、青色连接/投屏强调色、等宽设备标识和命令输出。颜色优先采用实际三页 HTML 与 DS frontmatter 一致的 token：背景 `#0b1326`、低层面板 `#131b2e`、主色 `#4edea3`、次色 `#4cd7f6`、正文 `#dae2fd`。
- 以三页的主体内容作为布局依据；DS 中更宽泛的多面板工作站布局不额外引入页面。
- 标题与正文使用易读无衬线字体，命令与数值用等宽字体。字体与图标本地可用，不以外部 CDN 可访问作为桌面应用启动条件。
- 设备选择通过设备管理卡片或工作台左栏顶部的设备下拉框完成，当前目标保持一致。下拉框末尾“添加无线设备”打开同页连接弹窗，复用直连/配对表单；不额外添加全局设备选择顶栏或导航侧栏。
- 原型品牌名为 DroidCraft Studio，仓库与现有应用名为 Remote Debug Bridge；品牌更名须确认，不能随界面还原自动更改包名、应用标识或版本号。

## 本地视觉资源与组件映射

- 色板在 `src/styles.css` 的 CSS 变量中集中定义，使用上述三页 HTML 的颜色；标题采用 Geist、正文采用 Inter，中文回退到系统无衬线字体，代码和设备读数采用 JetBrains Mono。
- 字体与 Material Symbols Outlined 图标字体放在 `public/fonts/`，均由本地资源加载。`src/icons.ts` 统一映射图标名称，装饰图标对辅助技术隐藏，操作按钮保留可读名称。
- 字体文件来源于 Google Fonts 的官方分发，版本对应下载时的 Geist v5、Inter v20、JetBrains Mono v24 与 Material Symbols Outlined v385；各字体的 OFL 与图标 Apache 2.0 许可证一并保存在 `public/fonts/`。不得在运行时改回在线字体链接。
- 应用品牌图标采用用户确认的深蓝圆角底、薄荷绿手机与青色连接符号；透明 PNG、ICO、ICNS 及接入说明见 [应用图标](app-icon.md)。欢迎页、设备页与工作台使用同一图标。
- P1 使用居中标题、状态样式品牌胶囊、主操作和三列连接指引；按用户要求移除本地环境检测卡片及检测按钮。品牌图标不表示 ADB 已连接，实际 ADB 状态在设备页显示。
- P2 使用主体标题卡片、带操作按钮的设备卡片、深色设备指标分区及右侧无线连接卡片；不绘制缺少真实数据支持的 RAM 使用率或流量图表。
- P3 使用独立的快捷控制、滑动、侧边返回、方向、屏幕参数、音频和终端卡片，图标按钮与数值控件沿用原稿风格。比例、方向和 DPI 快选点击即应用，DPI 滑块松开提交；每组提供青色强调的独立恢复按钮，自定义尺寸及 DPI 输入保留显式提交；终端与会话消息位于左栏，右侧为真实投屏区域。
- 原型模拟手机内容、固定性能指标、尚未纳入范围的功能和外部导航栏不作为视觉还原的可用功能引入。
