# Remote Debug Bridge 产品需求

状态：用户已于 2026-11-12 验收文档并要求准备下一步；按内嵌音视频技术路径和 F01–F09 核心范围推进。

更新日期：2026-11-13。本文定义首版范围；实施进度和实测结果统一见 [路线图](ROADMAP.md)。

## 1. 产品目标

为 Android 开发与测试人员提供一个本地桌面工具：连接并选择设备后，在同一个工作台中观看真实画面、播放设备音频、执行常用控制和调试命令，减少来回切换命令行与投屏窗口。

沿用 Tauri 2 + 原生 TypeScript + Rust，优先简单架构与短实施路径。首版只维持一个活动设备和一个投屏会话，设备列表允许多台设备。

核心闭环：检测环境 → 连接设备 → 选择目标 → 同页投屏与控制 → 查看执行结果 → 恢复修改过的参数并结束会话。

## 3. 页面与交互

### F01 欢迎指引

- 说明开启开发者选项、开启 USB 调试、连接 USB/无线以及手机端确认授权的操作。
- 欢迎页仅保留介绍、选择设备入口和三步连接指南，不展示环境检测板块或手动检测按钮。应用后台自动检测内置 ADB，设备页展示实际服务状态；失败通过错误提示反馈，可通过设备页刷新重试。不读取 PATH 或用户路径设置。
- 进入设备管理不以连接成功为前提；没有设备时也能查看连接指引。
- 状态栏来自真实检测，不默认写“Daemon Running”“RSA 已就绪”或固定版本号。

验收：系统未安装 ADB 时仍可使用内置版本；没有设备时也能进入应用。内置资源缺失时错误原因可见，修复资源后重试可更新结果。

### F02 设备管理与目标选择

- 列出设备标识、型号、USB/无线传输与 `device`、`unauthorized`、`offline` 状态；提供手动刷新，页面可见时进行低频自动刷新。
- 设备详情按可读取能力展示 Android/API、当前尺寸与 DPI、电量等。RAM、温度和厂商特有字段读取失败时显示未知，不阻塞连接。
- 首次发现一台设备可以提示选择；多台设备时由用户通过设备卡片或工作台左栏顶部下拉框明确选中目标，两处共享同一选择状态。下拉框显示型号、传输方式和设备标识，离线/未授权选项不可选；支持就地刷新。切换时清理原会话并保持在工作台，新目标由“开始投屏”启动。
- 未授权设备显示“在手机上确认授权”的指引与重新检测按钮，不承诺点击桌面按钮就能强制手机弹出 RSA 对话框。
- 当前目标离线后禁止新的控制操作，保留断连原因；不得自动把操作转向另一台在线设备。
- “重启 ADB 服务”明确提示会影响本机其他 ADB 客户端，用户确认后执行并重新发现设备。

验收：两台设备连接时，操作只作用于明确选择的设备；拔线、未授权、离线和重新连接能正确转换状态。

### F03 无线连接

- 工作台设备下拉框末尾提供“添加无线设备”选项，打开应用内弹窗，输入直连或配对参数；无需返回设备管理页。连接失败在弹窗内保留错误供修改重试，配对成功后继续填写连接端口。连接成功并确认目标在线后，选中该设备并关闭弹窗。关闭弹窗清除配对码，恢复焦点至设备下拉框。

- 直连：填写 IP 和连接端口，验证输入后连接并刷新设备列表；保留可读错误，不能仅凭进程退出码宣告成功。
- 配对：填写手机显示的 IP、配对端口、6 位配对码；配对成功后再检查连接，必要时输入独立的连接端口。配对成功不等同设备已在线。
- 直连要求设备已开启相应无线 ADB 监听；`5555` 仅为传统 TCP/IP 模式的常见值，不能套用为所有无线配对的端口。
- 连接历史只保存成功使用的地址与端口，支持重试；配对码只用于当次请求，不写入历史或日志。
- 扫码入口在能力未实现前不展示可点击的假操作。

Android 11+ 的无线调试支持配对码流程，具体连接步骤以 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi) 为准。

验收：错误地址、连接拒绝、配对码错误、配对成功但未连接均有独立反馈；成功后目标出现在真实设备列表中。

### F04 同页音视频投屏与直接操作

- 调试工作台内包含控制区、真实画面区、音频控制与命令结果区；投屏期间执行快捷控制和命令无需离开此页。
- 返回设备列表入口位于左栏设备选择卡片上方；卡片内展示当前设备及真实连接状态，投屏状态单独放在“投屏会话”标题旁，不表示设备连接状态。命令终端位于左侧控制栏底部，随控制栏滚动。会话消息也放在左栏，右侧可用区域全部用于投屏，不再保留横跨两栏的设备信息行。
- “开始投屏”启动目标设备会话；展示连接中、播放中、已停止、错误状态。支持停止、重试、静音及音量调整。
- 画面等比缩放，支持适应区域、缩放和应用内全屏。手机旋转、分辨率改变后画面与输入坐标同步更新，黑边不接收设备触控。
- 支持点击、拖动/滑动及基础按键控制。手机、平板、折叠屏画框切换若保留，仅代表显示布局；不能把调整页面外框伪装成修改设备真实形态。
- 声音来自真实设备输出；音频不可用时明确提示原因并允许继续仅视频模式。至少在支持音频捕获的验证设备上完成音视频同时播放验收。
- 结束会话、切换设备、断连和关闭应用时，释放该会话的媒体、输入、ADB 隧道及服务端资源；清理范围仅限应用自己创建的会话。
- 原型里的 60 FPS、14ms、H.264 硬解和 Opus 状态不是性能承诺。仅展示能够测量或确认的状态。

已采用的实现路径和需验证的兼容性见 [内嵌投屏调研](research/scrcpy-embedding.md)，真机与 WebView 验收记录见 [路线图](ROADMAP.md)。

验收：同一应用页面中播放真实画面与声音；点击/滑动作用于正确坐标；旋转、静音、停止与重新连接可用；无独立 scrcpy 桌面窗口。

### F05 高频控制

提供原型中的亮屏、锁屏、电源单击/长按、Home、最近任务、音量加减、静音、截图、展开通知栏和设备重启。重启在产品内确认后执行。

截图保存到用户选择的本地位置并显示结果；取消保存不报成功。按键与通知栏行为受系统支持限制，失败或不支持时显示真实原因。

验收：每项操作有发送中与成功/失败反馈，结果关联目标设备；点击操作不使整组按钮短暂置灰，连续点击按顺序执行，切换目标后丢弃旧目标尚未执行的操作。设备不可用时仍禁用控制；截图可以打开，重启后显示预期断连而不是继续保留在线假状态。

### F06 手势控制

提供底部上滑、短/中/长距离内容滑动、左右边缘返回及连续 3 次返回。坐标基于设备当前可操作显示区域计算，不能固定为原型的 `1080 × 2400`。

连续手势顺序执行；切换设备或断连时停止剩余操作。设备导航方式可能影响手势效果，不把命令发送成功等同系统已完成“返回”。

验收：横竖屏及至少两种分辨率下坐标仍有效；连续手势不会跨设备继续执行。

### F07 屏幕参数与恢复

- 通过四个按钮选择 0°/90°/180°/270° 方向，不再提供重复的方向下拉框；点击角度立即应用并固定方向；固定方向开关与自动旋转按钮立即生效，无需二次确认。方向组醒目显示“恢复原始方向”，仅恢复本次修改前的角度和自动旋转设置。
- 提供原型的 21:9、18:9、16:9、4:3 尺寸预设、自定义宽高与 DPI。比例仅通过预设按钮选择，不提供重复下拉框；比例与 DPI 预设点击即应用，DPI 滑块松开即应用；自定义数值填写后用 Enter 或应用按钮提交。选中态以设备回读为准，失败提示真实原因；数值显示真实单位。
- 输入在前后端均验证为合法范围的整数：尺寸每边 200–7680 px，DPI 72–1000；设备拒绝合法范围内的值仍显示实际错误。读取当前值、应用变化、回读确认；部分步骤失败时明确哪些已生效。
- 比例与 DPI 组分别提供醒目的“恢复默认比例 / 尺寸”和“恢复默认 DPI”按钮，独立清除对应覆盖，互不影响。保留合并恢复默认尺寸和 DPI 入口，以及“恢复本次修改”回到本次修改前设置；恢复默认与回到原值含义明确区分。
- 应用修改前记录可恢复的尺寸、密度、旋转和触控轨迹设置；提供“恢复本次修改”。无法读取原值的项先说明，不能假称可恢复。
- 正常结束会话时尝试恢复本次修改；断连或异常退出无法恢复时，下次连接同一设备提示恢复。任意终端命令的副作用不属于自动恢复范围。

验收：改变尺寸/DPI 后实际画面和读数同步；恢复使用真实原值或设备 reset 能力，不写死某机型默认值；失败保留可恢复记录。

### F08 单次命令终端

- 输入的是目标设备 `adb shell` 后的命令。空命令不提交；Enter 或按钮执行，运行时可取消。
- 保留原型预设：当前前台窗口、显示属性、Android 版本、电池、应用内存、第三方包名；需要包名的查询先要求输入包名。
- 展示实际执行命令、目标设备、stdout、stderr、退出状态及耗时；输出作为文本显示。
- 允许 Android 设备端 shell 管道，但不能把输入拼接到电脑端 `sh -c` 或系统命令解释器。
- 单次运行上限 30 秒，stdout、stderr 分别保留最多 256 KiB，命令输入最多 8192 字节；超限明确标记，避免 UI 长时间阻塞。该入口不是持续 shell、持续 Logcat 或批量任务引擎。
- 清空仅清除显示，不取消运行中的任务；取消单独处理。取消本地等待不保证回滚已发生的设备副作用。

验收：成功、错误、超时、取消和输出截断都可区分；命令在投屏时可执行，不阻塞画面与输入。

### F09 反馈和状态一致性

通用操作提示采用不占布局空间的临时 toast，正常提示约 3.5 秒、错误约 8 秒后消失；新提示替换旧提示并重新计时，不再显示顶部常驻提示条。设备状态、参数恢复提醒及终端输出仍在各自区域保留。

会话状态采用 `idle → starting → streaming → stopping → idle`，失败进入 `error` 并可清理后重试。音频有独立的可用/静音/失败状态，音频失败不得伪装整条连接成功或强制中断可用画面。

活动设备、会话和请求均有标识。异步结果只更新匹配的目标与会话；多次点击开始、快速切换目标、旧请求迟到不能创建多个后台会话或污染新页面。

## 4. 界面与质量要求

- 视觉遵循 [设计落地规则](design/README.md)：深色、紧凑、绿色/青色强调、中文为主，命令与数值使用等宽字体。
- 目标桌面布局以 `1280 × 800` 和 `1440 × 900` 检查；控制区可滚动，画面区保持可见，长命令与错误可阅读。当前脚手架窗口尺寸需要在界面阶段调整。
- 应用使用统一的透明圆角品牌图标，覆盖安装包、系统应用/默认窗口图标、页面品牌入口及 favicon；提供 PNG、ICO、ICNS 本地资源。
- 本地启动不依赖 CDN、在线字体或远端图片；设备 IP、命令输出与配对信息不上传到云服务。
- UI 不因设备发现、命令执行或视频解码失去响应。首个技术验证建议从视频长边 1280、30 FPS 开始，实际能力与默认值由验证结果决定。
- 连续音视频播放 10 分钟，检查卡顿、累积延迟、内存增长；完成至少 5 次启停和设备切换，不残留会话。数值化延迟及音画同步目标在技术验证后确定，不引用原型假指标。
- 推荐以当前 macOS 主机和 Android 12+ 真机建立首个验证基线；Android 11 音频及 Windows/Linux 支持范围另行记录实测结果，未经验证不作兼容承诺。

## 5. 交付完成条件

核心范围 F01–F09 均有实际验收记录；一条 USB 和一条无线连接完成“选择设备 → 同页音视频 → 控制/终端 → 恢复 → 停止”闭环；异常路径通过且没有模拟业务结果；交付包、依赖设置和已知限制有说明。

验收执行遵循根 [AGENTS.md](../AGENTS.md) 的验证约束。未执行的编译、真机、平台或安装包检查明确标为未验证，不能据此宣布交付完成。

2026-11-13 用户调整验收安排：第 2 步尚未覆盖的验收项在后续实际使用中补做，允许先推进后续功能开发；功能范围和最终验收标准保持不变，待验清单见路线图。

## 6. 实施基线与后续发布事项

- 按已验收文档采用“Rust 管理 scrcpy-server + Tauri 二进制通道 + 页面内解码播放”路径，先完成真实 WebView 技术验证。
- 当前只以 F01–F09 为首版实施范围；X01–X04 保留为范围变更候选，未经明确纳入不扩展实现。折叠尺寸预设不能替代真实折叠能力。
- 先在当前 macOS 与 Android 真机上验证，携带锁定版本的 scrcpy-server 与官方 Platform-Tools 37.0.1 ADB。按用户要求纳入 Windows x64、Linux x86_64、macOS arm64/x86_64 的 ADB 资源，命令只通过内置可执行文件执行。最低系统版本、各平台完整应用兼容性与正式产物仍需在交付阶段验证；Windows/Linux ARM64 尚不支持。

用户提供的源码与下载授权已记录在 [资源准备说明](development/scrcpy-setup.md)。后续若调整技术方向，再依据 AGENTS 确认方案。
